## 取舍与限制

详见 `docs/规则核验与取舍.md` 与 `docs/素材来源.md`。

- 六人史诗按官方为10轮；六人强制合约，不给无效组合。
- Asmodee原图为立体盒照，换成BGG出版社提供的平面封面；均目视确认。基础仅600px，不上采样；起义长边1024px。
- 六人多方平局加队内让出：起义p14、六人p5/PDF p11，人工裁定。血脉萨多卡未核清效果：血脉p10，人工核对后再输入。
- 领袖手工填写，清单提醒特殊实物依赖和剔除；没有领袖自动规则引擎。Chaumurky保留英文实物名。
- 单/双人按规则书或官方companion驱动劲敌；自由混牌仅兼容说明。
- 房间无账号登录；主持权限随本机浏览器保留，第一版没有丢失主持凭据后的在线接管流程。
- 历史修改从原房间重开核对再结算，同一gid覆盖原存档；不伪造全程得分构成。
