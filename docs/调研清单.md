# 沙丘：帝国助手 · 做 / 不做清单（待确认）

调研日期 2026-11-05。完整报告在 [docs/调研/](调研/)：英文社区、中文社区、已有工具、规则资料与版本差异四份。BGG 两个游戏共 **199 个 Files 条目**，定向取得 **3 帖 / 122 楼**；官方英文与简中 **14 份 PDF**。中文取得营地勘误与 B 站规则整理，集石/小红书需登录、贴吧安全验证，**没有中文评论普查数据**。数字是采集范围，不是痛点发生率。

## 先说五个事实

- **两个主版本都可搭配三个扩展**，但混用要换牌、覆盖板、调整领袖和对手设置。血脉不是起义专用；基础＋血脉需排除部分起义机制牌。开局选主版本，再列兼容扩展与组合清单。[官方起义 p18](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_UPRISING_Main_Rulebook_23-10-12.pdf)、[血脉 p3、p7](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_BLOODLINES_Rulebook.pdf)
- 正式简中名是 **《伊克斯崛起》《不朽之躯》《血脉永续》**，其中“不朽”只是简称。中文资料由官方提供，中文支持方列 Gaea/iYingdi 盖娅；营地早期简中与 Broadway Toys 的新版 BGG 记录应分别注明。[中文核对报告](调研/调研_中文社区.md)
- **起义六人不需要基础版**：两队各三人、最多 9 轮，任一玩家达到 10 分触发轮末结束，最后比较团队总分；不支持标准五人自由混战。[官方补充册](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_UPRISING_Rules_Supplements_23-10-12.pdf)
- 本次最有支撑的需求是**规则防错、混扩设置和冲突平手速查**。BGG 冲突平局辅助卡 **68 赞**，跨版本全扩辅助卡 **44 赞**；计分纸也有，但不能据此把沙丘做成奥丁式完整终局分类求和。[英文报告](调研/调研_英文社区.md)
- **官方已有 Game Room companion，第三方也有计分与同步工具**。官方 iOS 语言栏没有中文；新站的价值应在中文规则、配置过滤和少操作，不是重复做自动对手或数字版。[工具对比](调研/调研_已有工具.md)

## 要你决定的三件事

**A. 六人团队模式首版就做吗？建议先做配置、专属提示和团队终局，不做自动战斗裁定。**

- 它是起义盒内的正式模式，不能被藏成“未来扩展”；开局至少应让用户知道六人规则入口。
- 有两名指挥官、队内让出冲突名次、共享影响力等例外，不能照搬四人规则。最小版：选队伍和指挥官→提示交替座位、4/1 起始分、9 轮→四名盟友分别处理战斗→最后三人得分相加。
- 本轮没有六人玩家使用量统计；如果你很少开六人，也可以首版只给官方资料入口，稍后再做团队房间。[六人官方规则](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_UPRISING_Rules_Supplements_23-10-12.pdf)

**B. 要不要冲突计算器？建议先上平局速查，计算器作为可选第二步。**

- 需求证据比普通资源账本强：专门的平局辅助卡 68 赞。最小计算器只输入大家已经在实物上算好的最终战力，输出名次/奖励档位，不重建兵力、卡牌和整套冲突牌库。
- 起义要额外提示每人的沙虫奖励倍率、作战图标不翻倍；六人队内平局和血脉指挥官效果不能错误套用普通名次算法。
- 简单对局看实物战力轨即可，计算器应随时可跳过。[平局辅助卡](https://boardgamegeek.com/filepage/215158)、[起义 p14](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_UPRISING_Main_Rulebook_23-10-12.pdf)

**C. 史诗模式与任意混牌要不要一起做？建议首版只做标准模式及三个扩展，暂缓史诗和自由混牌。**

- 史诗是官方模式，目标 12 分，准备和冲突牌库也变；不能只改终局阈值。它可以以后作为完整配置加入。
- 自由混牌涉及门泰特相关牌剔除、旧冲突缺少作战图标、领袖需要基础储备牌等问题。先提供官方兼容说明，不做自选牌池编辑器。[伊克斯 p10](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_RISE_OF_IX_Rulebook_22-2-11.pdf)、[起义 p18](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_UPRISING_Main_Rulebook_23-10-12.pdf)

## 不做（留在线下或明确暂缓）

| 环节 | 理由 |
|---|---|
| 资源钱包、驻军/战力/影响力四轨镜像 | 实物看得见；手机再记一遍会不同步。保留规则解释，不要求每次增减都输入 |
| 议会席位与每轮说服力的持续账本 | 普通局的关键是记得揭示奖励和时机；目前证据不足以支持逐回合录入所有卡牌 |
| 手牌、牌库、购牌区、密牌内容、抽牌 | 属于游戏本体与隐藏信息，既增加输入又接近数字版 |
| 轮到谁的强制轮转系统、每人“已揭示”打卡 | 实物轮流操作容易判断；揭示不是彻底退出战斗，照搬阿纳克全员 Pass 会误导 |
| 自动对手 AI、House Hagal 电子牌堆 | 官方 Game Room 已有；本项目提供入口与配置指引 |
| 完整卡牌图库/逐张规则引擎 | 版本、印次和混扩维护成本高；先做有出处的易混卡 FAQ |
| 自动拍照识别版图、自动猜分 | 只有个别需求，未验证可靠方案；错识别会破坏终局可信度 |
| 全程得分归因、复杂成就、ELO、赛事管理 | 依赖额外记录；先保留最终赛果，不强迫玩家为统计服务 |
| 战斗策略推荐、胜率/手牌推算 | 超过规则辅助边界，影响线下博弈与隐藏信息 |
| 强制计时、线上对战 | 计时虽有现有 App，但本轮缺少必需证据；线上对战超出用户范围 |
| 首版开放官方 App 特有变体、自制扩展、任务外新产品 | 每种模式单独核查工作量大；本次范围固定为两个主版本和三个指定扩展 |

以上“不做”主要是用户的实物优先原则与本轮证据权衡，不是宣称这些功能永远无人需要。[完整证据及局限](调研/调研_英文社区.md)
