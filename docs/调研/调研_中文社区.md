## 2. 中文资料揭示的真实问题

### A. 早期中文版有实体卡牌翻译勘误

[营地官方资料页](https://www.iyingdi.com/tz/post/2327171)显示 **6 点火 / 29 回复**；文章发表于 2021-03-29，勘误段标注更新于 2021-05-14。

- 第一批勘误涉及操作市场、绕过协议、基因操控、海伦娜·里奇塞：**4 种、5 张卡**。
- 另列哥尼哈莱克、奢靡两种卡的连接词修正：“或”应为“并且”。
- 这支持一个非常具体的功能：FAQ 加“旧印次中文勘误”，让玩家确认手中实物；不应把修正当成新平衡规则，更不能假设所有人的卡都同一印次。
- 该页是早期营地版本资料，不能自动代表 2025 中文新版、起义或血脉的所有卡牌印次。

### B. 中文规则用词和动作归属容易混淆

[B 站规则整理](https://www.bilibili.com/opus/813728755927220291)（作者 spj233，页面标注 2025-01-24 编辑）专门解释“失去部队回供应区”和“撤回部队回驻军”、特使召回后的再使用，以及基础部队与伊克斯无畏舰不等同。文中注明转载来源为上述营地页，**两者不算两组独立玩家样本**。

建议做术语速查：特使回合 / 揭示回合 / 战斗阶段；供应区 / 驻军 / 冲突区；部队 / 战斗单位；销毁 / 弃牌 / 撤回。用自己的话说明，再指向官方页码。这个证据支持“需要中文解释”，不支持“必须在线实时记录部队”。

### C. 有跨版本教学和勘误资料，说明版本标签必须清楚

[起义勘误视频](https://www.bilibili.com/video/BV1yK421h7Su/)与[血脉四人实战](https://www.bilibili.com/video/BV1jGkWY3EkF/)可以作为学习入口。标题和简介显示内容分别针对起义和血脉；未读取评论，所以不提供“多少人反复问沙虫”的伪统计。

建议 FAQ 每条注明适用版本与扩展。例如基础版门泰特条目不应出现在纯起义局；不朽研究轨不能被“任意派系影响力”推进。正式裁定回到[官方 FAQ](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_FAQ_25-1-13.pdf)，不是仅用教学视频互相印证。

### D. 二手中文介绍不能直接当兼容规则

部分中文商品/资讯页面把起义六人写成需要“基础＋起义合体”，或声称没有官方简中规则。实际起义盒内自带六人组件与补充规则，官方资源页也已提供 SCN 简中主规则和补充册。应以[官方资源](https://direwolfdigital.com/dune-imperium/resources/)及[起义补充册](https://d19y2ttatozxjp.cloudfront.net/pdfs/DUNE_IMPERIUM_UPRISING_Rules_Supplements_23-10-12.pdf)为准，避免把过时介绍继续传给用户。

## 5. 结论与仍需补证之处

中文可访问资料最明确的价值是**术语对照、旧版勘误、版本专属规则入口**。没有足够中文用户样本证明资源账本、实时议会计算器或完整牌库追踪是首要需求。若以后补做登录后的集石/小红书/贴吧，应记录帖子时间、原链接、去重人数、具体错误及是否线下实体局，独立补充报告；本次不据缺失样本阻止已有证据充分的功能进入待确认清单。
