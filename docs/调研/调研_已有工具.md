## 4. 对新站的建议

1. 核心卖点用“中文、按版本过滤、易错点就地解释、开局到收局少查书”。不要用“第一个沙丘计分工具”。
2. 多人房间可以复用系列，但只同步配置、流程和最终结果；不要求全程维护资源、牌库与四派系。
3. 官方 companion 外链优先解决单/双人自动对手。Arrakeen Scouts、Blitz! 等官方变体不纳入首版自制引擎。
4. 历史对局保存版本、人数、扩展和领袖；把基础、起义、史诗、六人团队的数据分开。ELO/赛事组织需求只来自小样本，不作为首版必做。
5. 真人需求帖有人想拍照录分，但本轮没有验证可用识别方案；不建议为此做高维护的图像识别或默认猜分。
